# Fonts

Self-hosted WOFF2 files from Google Fonts (Latin and Latin Extended subsets), used offline by the PWA.

- Agbalumo: wordmark and recipe titles only
- Abril Fatface: headings
- Fredoka (variable, weights 300–700): UI

All three are licensed under the SIL Open Font License 1.1 (free for commercial use, can be bundled with software): https://openfontlicense.org
